# Why Twofold exists

## Tools you rent

A diff tool is a utility. It shows two files side by side and marks the differences. It has no servers to run and no cloud to pay for, and it gets no better because you paid again this month. Yet the good-looking diff tools on the Mac have mostly moved to subscriptions. You pay every month for software that sits on your own disk, and when you stop paying it stops working.

We don't accept that. A tool you use every day should belong to you.

## Tools that get abandoned

The usual alternative isn't much better. You pay once, the developer moves on, and the app slowly rots. Nobody fixes it for the next macOS. The bugs you report go unanswered, and one day it won't launch at all. You paid for the software, but you were really renting the developer's interest, and that ran out.

Paying once doesn't fix this. What fixes it is code that nobody can abandon.

## What we do instead

- **Open source under the GPL v3.** The code is public and stays public. If we stop working on Twofold, anyone can carry on, and no one can lock it away in a closed fork.
- **Completely free, forever.** Build it yourself or download a release from GitHub. It's the full app with nothing held back, and there is no paid version.
- **No subscription, ever.** We may one day offer a Mac App Store build to cover the project's small running costs, but that is undecided and needs its own plan, because Apple's sandbox would cost the app features. Whatever comes of it, the free, full version on GitHub stays.
- **No accounts, no telemetry, no lock-in.** It reads two files and shows you the difference. That's all it does.

## Why now: the age of AI

Software like this used to take a small company years to build, and a company has to pay its staff, so subscriptions followed naturally. That reasoning no longer holds. One person working with AI can build a fast, native, well-designed app in a fraction of the time, and that changes what is worth charging for.

When building software costs this little, everyday tools should be shared like a public library, not rented out. Building with AI also makes it easy to contribute: this repository is set up so that a person, an AI agent or both together can read it, understand it and improve it (see `CLAUDE.md`). Rather than fear what AI does to software, we want to use it to make good software that everyone owns.

## In short

- Software you depend on shouldn't stop working when you stop paying.
- Software you paid for shouldn't die when its developer loses interest.
- Open code solves both problems, and AI makes open code cheap to build.

So take Twofold, use it, fork it and make it better.
