Looking for Meld on a Mac?
Here's a native one.

Meld is a great open source diff and merge tool, built for Linux with GTK. There's no official macOS build. Twofold shares Meld's spirit, free and GPL, but it's made for the Mac.

Where Twofold is better

  • ✓Made for macOS. AppKit and Core Text, Mac keyboard shortcuts, Dock drop, and themes that follow the system. No GTK runtime.
  • ✓Maintained for the Mac. Built and released from the main repository, as a universal app for Apple silicon and Intel.
  • ✓Fast. 100,000 lines diff in under 60 ms; scrolling stays at 120 Hz.

Where Meld is better

  • –Merging and three-way. Meld edits, merges and compares three files at once. Twofold v1 compares two and doesn't edit yet.
  • –Version control view. Meld can browse a repository's changes directly. Twofold works through git difftool instead.
  • –Cross-platform. Meld runs on Linux and Windows too. Twofold is Mac only.

Should you switch?

If you came to the Mac from Linux and miss Meld for reading diffs, Twofold is the closest native, free and open source equivalent. If you need Meld's three-way merge today, its community Mac builds still work, with a non-native interface.

Questions

Is there an official Meld for Mac?

Meld's official releases are for Linux and Windows. Mac builds come from the community. Twofold is a native, open source alternative made for macOS.

Is Twofold open source like Meld?

Yes. Twofold is licensed under the GPLv3, and the full source is on GitHub.

Can Twofold do three-way merges like Meld?

Not yet. Three-way merge for git mergetool is on the roadmap.
