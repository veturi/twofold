Where Twofold is better

  • ✓No Xcode required. Download one app, not a multi-gigabyte developer suite.
  • ✓Highlights that help. Changed words are marked inside each line, refined to characters where only part of a word moved.
  • ✓Modern layout. Unchanged runs fold away, an overview strip shows every change, and ⌘↓ / ⌘↑ glide between them.
  • ✓Fast folder comparison. Results stream into a sidebar while the comparison runs in parallel.

Where FileMerge is better

  • –Merging. FileMerge can merge two files, optionally against a common ancestor. Twofold v1 only shows differences.
  • –Older macOS. Twofold needs macOS 26; FileMerge comes with whatever Xcode you have.

Should you switch?

If you use opendiff or FileMerge to read diffs, Twofold is a straight upgrade, and it works as git difftool the same way. If you merge with FileMerge, keep it around until Twofold's merge lands.

Questions

What is a good replacement for FileMerge on Mac?

Twofold is a free, open source and modern replacement for reading diffs of files and folders. It doesn't need Xcode. FileMerge still has merging, which Twofold doesn't have yet.

Can Twofold replace opendiff in git difftool?

Yes. Set diff.tool to twofold with the command twofold --wait "$LOCAL" "$REMOTE".

Do I need Xcode to use Twofold?

No. Download the release and run it. Only building from source needs the Xcode Command Line Tools.
