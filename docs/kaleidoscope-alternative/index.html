Where Twofold is better

  • ✓It's free, for good. No subscription, no license key, no account. The GPL means nobody can take it away or put it behind a paywall later, not even us.
  • ✓Fluid layout. Changes on each side are joined by curves through the middle, and both sides glide so the change you're reading stays lined up, without filler lines.
  • ✓Fast on big files. 100,000 lines diff in under 60 ms, and scrolling stays at 120 Hz.
  • ✓Nothing phones home. No telemetry, no license server.

Where Kaleidoscope is better

  • –Three-way merge. If you resolve git conflicts in a GUI, Kaleidoscope does that today.
  • –Older macOS. Twofold needs macOS 26 or later.

Should you switch?

If you mostly open a diff to read what changed, in code review, after a git pull, or between two exports, Twofold covers that well and costs nothing. If you merge conflicts in a GUI every day, stay with Kaleidoscope for now, and keep an eye on our roadmap.

Questions

Is Twofold a good free alternative to Kaleidoscope?

For reading diffs of text files, images and folders, yes. Twofold is native, polished and free. Kaleidoscope still does more, including three-way merge.

Can I use Twofold as git difftool like ksdiff?

Yes. Install the twofold command with make install and set it as your diff.tool. git difftool --dir-diff opens a whole tree in one window.

Does Twofold have a subscription?

No, and it never will. It's free from GitHub. The planned Mac App Store version is a single 4,99 € purchase.
